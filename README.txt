ระบบทะเบียนครุภัณฑ์ สำนักงานพัฒนาชุมชนจังหวัดพังงา

ไฟล์:
- Code.gs : โค้ดฝั่ง Google Apps Script
- index.html : หน้าเว็บไซต์

วิธีติดตั้ง
1. เข้า https://script.google.com/ แล้วสร้างโครงการใหม่
2. วางเนื้อหา Code.gs ลงในไฟล์สคริปต์ และสร้างไฟล์ HTML ชื่อ index แล้ววางเนื้อหา index.html
3. ไปที่ การตั้งค่าโครงการ > คุณสมบัติของสคริปต์ (Script Properties) เพิ่ม:
   ADMIN_PASSWORD = ตั้งรหัสผ่านที่คาดเดายากของคุณเอง
   ไม่ต้องส่งหรือเผยแพร่รหัสผ่านนี้ให้ผู้ใช้
4. บันทึก แล้วเลือกฟังก์ชัน setupSheet_ และกดเรียกใช้ครั้งแรกเพื่อสร้างชีต/อนุญาตสิทธิ์ Google Sheets และ Drive
5. เลือก ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ > แอปเว็บ
6. ดำเนินการในชื่อ: ฉัน (เจ้าของสคริปต์). ผู้ที่มีสิทธิ์เข้าถึง: เลือกตามนโยบายหน่วยงาน (แนะนำจำกัดเฉพาะบัญชีหน่วยงานหากทำได้)
7. เปิดลิงก์แอปเว็บ

หมายเหตุสำคัญ
- ข้อมูลถูกเก็บใน Google Sheets ที่สร้างโดยสคริปต์ ดูลิงก์ได้จากเมนูตั้งค่า > เปิดตารางข้อมูล
- การส่งออก PDF/XLSX จะสร้างไฟล์รายงานใน Google Drive และคืนลิงก์ไฟล์
- ผู้ใช้ที่เปิดเว็บได้สามารถดูข้อมูลทั้งหมดได้ แต่เพิ่ม/แก้ไข/ลบได้เฉพาะผู้ดูแลที่เข้าสู่ระบบ หากข้อมูลมีความอ่อนไหว ให้จำกัดผู้เข้าถึงเว็บแอปและชีตด้วย
- ภาพประกอบเวอร์ชันนี้รองรับลิงก์รูปภาพที่เปิดดูได้ การอัปโหลดจากอุปกรณ์โดยตรงยังไม่ได้ทำ
- การเรียงรายการใช้การเปรียบเทียบภาษาไทย และเรียงวันที่ใหม่ไปเก่าในกรณีชื่อรายการเหมือนกัน
- ตรวจสอบสิทธิ์การส่งออกและการเข้าถึงไฟล์ใน Google Drive หลังติดตั้ง

หมายเหตุฉบับปรับปรุง: รหัสผู้ดูแลเริ่มต้นจะถูกตั้งใน Script Properties ชื่อ ADMIN_PASSWORD เป็นค่าเริ่มต้นครั้งแรกเท่านั้น ไม่แสดงในหน้าเว็บ ควรเปลี่ยนรหัสผ่านก่อนเปิดใช้จริง
รองรับอัปโหลดภาพ PNG/JPG/GIF/WEBP ขนาดไม่เกิน 5 MB โดยบันทึกใน Google Drive โฟลเดอร์ภาพประกอบทะเบียนครุภัณฑ์ พังงา
